
# 🌍 World Population Age Analysis
SQL and Power BI analysis of global population age distribution


## 📊 Project Overview

This project analyzes global population trends by age group using SQL and Power BI.

The goal is to transform raw demographic data into meaningful insights through data cleaning, SQL analysis, data modeling, and interactive dashboards.

The project explores how population age structures differ between countries, continents, and income groups over time.

---

## 🎯 Project Objectives

- Analyze global population distribution by age group
- Compare countries, continents and income groups
- Identify demographic trends over time
- Build an interactive Power BI dashboard
- Practice SQL data analysis techniques

---

## 🛠️ Tools & Technologies

- MySQL
- Power BI
- Data Modeling
- Data Cleaning
- Data Visualization

---

## 📈 Dashboard Features

The dashboard includes interactive visualizations such as:

- Population by age group
- Population trends over time
- Country comparisons
- Continent comparisons
- Income group comparisons
- Average years of schooling
- Interactive slicers and filters

---

## 📊 Key Insights

- Europe has one of the highest proportions of people aged 65+.
- Low-income countries have the youngest populations.
- Population age structures differ significantly between income groups.
- Interactive filtering makes it easy to compare regions and countries.
